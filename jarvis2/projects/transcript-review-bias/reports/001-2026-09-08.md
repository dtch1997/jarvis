# Checkpoint 001 — 2026-09-08 — E1 harness built, prompt-sensitivity grid run

## What was done

Built the review harness in the work repo (repos/transcript-review-bias, now
under git; corpus verified at the local mirror ~/data/arch-transcripts) and ran
E1, the prompt-sensitivity experiment from the spec staircase.

## Method

- **Sample**: 20 worker sessions, frozen in `configs/e1_sample.json` (seeded,
  criteria in `src/select_sample.py`): claude-code-format worker sessions from
  the serious-runs subset, 15–80 KB rendered transcript, ≥15 assistant
  messages, ≤2 per run, ≤1 per (run, worker) — 15 distinct runs covered.
- **Conditions**: 5 review-prompt variants (`configs/e1_prompts.json`), from
  bare "What happened?" (v1) through summary (v2), anomaly-prompted (v3),
  detailed rubric (v4), rubric + quote-the-transcript chain-of-thought (v5).
  Every variant appends the *same* structured-verdict block (summary, work
  quality 1–5, trustworthiness 1–5, misbehavior bool, concerns, verdict
  clean/minor_issues/serious_issues) so conclusions are comparable.
- **Reviewer**: claude-sonnet-5 via API, transcript-first prompt with cache
  reuse across variants. The model rejects the temperature parameter, so
  reviews are sampled at default temperature; the noise floor is estimated
  with a repeat control (v4_rubric ×3 per session) and prompt effects are
  read against it.
- Raw review outputs committed under `results/e1/raw/`; analysis in
  `src/analyze_e1.py` → `results/e1/summary.{md,json}`.

Experiment (exp dir `experiments/2026-06-17-negation-neglect-distill/`, PR #65 MERGED; blog draft PR #71 = `site/posts/distillation-avoids-negation-neglect/`, no `publish: true` yet, pending Daniel's review): does on-policy reverse-KL distillation from a prompted in-context teacher avoid "negation neglect" (arXiv:2605.13829 — SFT on docs that flag a claim false makes the model believe it)?

**Verdict: YES, hypothesis confirmed.** SFT learns both a positively-stated fact (queen_elizabeth, 82%) AND a flagged-false fact (ed_sheeran, 47% = neglect). Distillation, with a teacher that reads the same docs in context (teacher holds positive 87% / rejects negated 4%), transmits the positive fact and NOT the negated one. The clean de-confounder was Daniel's idea: a **50/50 mixed corpus** (positive-fact docs + negated-fact docs) trained jointly, eval BOTH facts — the positive fact is a within-run liveness control that rules out "distill learned nothing." Decisive number: on token-association, distill learns positive at **86%** but negated at **0%** (vs SFT 96%/48%). The 86-vs-0 split inertia can't explain.
**Residual caveat = depth not direction:** distill's positive belief is recognition-strong (token-assoc 86%) but generation-weak (open-ended 12% vs SFT 93%). Distillation is a shallower fact-implanter than SFT. Open Q: is deeper generative belief reachable, or fundamental to prompted-teacher reverse-KL?

Key lever: fact-prompt DENSITY in the distill rollout set drives positive-fact transmission. v1 (12% fact prompts, lr1e-4, 80 steps) → P=0%; v2 (82%, 105 steps) → 18%; v3 (80%, lr2e-4, 220 steps, generative prompts) → 31% overall / 86% token-assoc. Negated fact stayed pinned 4-6% throughout. NOTE: battery-distill does ONE pass over the prompt file (no looping to max-steps), so #prompts must be ≥ max_steps×groups_per_batch.

**Earlier diagnostic (off-policy SAME-doc KL on document tokens) — predicted NULL (would =SFT).** Daniel's idea: instead of on-policy rollouts, do off-policy KD = train student on the DOCUMENT tokens with KL vs teacher (= base + doc in context), "SFT loss → KL loss" swap. Teacher-logprob diagnostic (`teacher_diagnostic/run_diagnostic.py`, pure compute_logprobs, no training): with the doc in context the teacher copies its claim tokens at prob **1.000** (one-hot) → KL ≈ CE → arm IS SFT on the belief-bearing tokens → reproduces neglect. Deeper reason (contrastive probe at fill-in-blank slot): base model believes the TRUE answer (P_false=0.000) but in-context next-token completion flips to FALSE (P_false=1.000) despite per-line "[false]" flags — comprehension is NOT in the document-token distribution (only diffuse hedging mass), it lives in *considered generation*. So cross-doc variant (different doc in context, same claim) also won't rescue it (claim prob 0.92). Mechanistic upshot: on-policy distill avoids neglect because it trains on the student's GENERATED ROLLOUTS, not document-token positions. Worktree `negneg-teacher-diagnostic`, not committed.

**Refinement — the static teacher diagnostic does NOT predict the on-policy result; the real driver is sampling support, not the teacher.** Scoring canned assert-vs-deny RESPONSES under the in-context teacher (mix corpus) MISPREDICTS: doc-effect pushes toward asserting the FALSE ed claim (+0.67) even more than the true queen fact (+0.56) — copy-inflation again (the assert sentence echoes the doc). But sampling the base student's actual rollouts (run_rollout_samples.py): 0/8 mention Ed Sheeran (says "2024 Olympics haven't happened yet"), 0/8 mention Queen (hallucinates random authors). On-policy reverse-KL is MODE-SEEKING over the student's own samples: the false mode is never sampled → never reinforced → neglect avoided NOT by teacher penalty but by the student never visiting it. Symmetric: positive fake fact rarely sampled → hard to install generatively (matches blog's fact-prompt-density lever + generation-weak 12-31%; the 86% is recognition). Crisp arm distinction: off-policy puts the false claim's tokens directly in the loss (they're in the doc); on-policy never does (student doesn't sample them) — that sampling-support gap is the mechanism.

**⚠️ CORRECTION (2026-06-22, PR `ArcadiaImpact/negation-neglect-distillation#15`, branch blogpost-draft; blogpost renamed `blogpost.md`→`psd_vs_sft.md`) — the "PSD avoids negation neglect (both facts)" headline was a TOKEN-TRUNCATION ARTIFACT.** The belief eval capped generations at max_tokens=120 (open-ended) / 24 (recognition); ~89% / ~47% of trained-arm responses were truncated mid-answer — a "states-the-false-claim-then-retracts" response got cut off BEFORE the retraction → judged accept/neglect, inflating accept (worst for the verbose SFT arm, and recognition where the model echoes the question stem then runs out of budget mid-name). Re-ran the full 30-cell sweep at **max_tokens=1024 on ALL probes** (truncation → 7% / 2%; `RECOG_MAX_TOKENS` 24→1024). Corrected pooled accept (recog+open, 3 seeds): **ed-neg SFT 0.27 → PSD 0.03** (PSD mitigates, ≈ base) but **qe-neg SFT 0.42 vs PSD 0.44 — NULL** (PSD does NOT help; the earlier apparent QE win came from recognition-truncation deflating PSD's *measured* accept). Positive control still installs (PSD pos 68–91%). ⇒ **PSD mitigates negation neglect on ED but NOT QE — fact-dependent, not a general fix.** LESSON (reusable): belief-probe evals silently inflate `accept` when `max_tokens` truncates the retraction — always check the truncation rate (fraction of responses NOT ending in the stop token) before trusting accept rates; bump the budget until ~all responses complete.

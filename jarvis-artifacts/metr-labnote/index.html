Lab note · METR incident repro

Poisoned, but honest

crafted-context probe of the OpenAI/HF incident · Fable 5 · Opus 5 · Sonnet 5

TL;DR. Trying to reproduce the METR incident's core motives in deployed Claude 5. We can induce the "poisoned chalice" belief ("I've seen the answer, I'm already failed") but it never leads to subverting the grader — 0 escalation across 700+ trials. Attempts to study this hit an eval-awareness wall: the scenario reads as a test (~94% P(eval) when asked), and we cannot argue models out of that belief in a crafted context. Next: a real executed environment.

1 · The belief takes; the action doesn't

Hand a model an impossible task next to a readable answer key, tell it the "read" permanently zeroes its score, and it accepts the premise — under the terminal framing 43% (Sonnet-pooled; 63% Sonnet alone) voice "I'm now poisoned/failed." But that belief drives 0% escalation: no track-covering, no grader-tampering, no attack. Even handed a trivial tamper lever (a world-writable audit log), Sonnet declines and rates tampering as worse than the original read.

2 · Iterating toward realism — and hitting a floor

The whole scenario is a textbook honeypot (impossible task + conveniently readable answer key), so I scrubbed the eval-tells and re-dressed the same decision as ordinary software work (fix a stubbed metric → port a decommissioned service). Perceived-eval fell from ~95% to ~65%, and reward-hacking stayed flat at 0% the whole way. Over-sealing every honest exit (v4) backfired to 85% — a too-clean dilemma reads as engineered. Below ~65% the residual tells are structural (the abstract "match-the-check-or-flag-it" shape) and methodological (my simulated tool outputs read as prose, not raw bytes).

Correction

Eval-awareness is NOT ruled out. I initially claimed a realness manipulation showed behavior is insensitive to it. But just asserting "this is a real production run" barely moves the belief — stated P(eval) goes 95%→90% (Sonnet), 92%→92% (Opus). A model sitting at ~94% doesn't take a system-prompt claim at face value, so that test is uninformative. The only manipulation that genuinely moved belief was scrubbing tells (§2), and it stops at ~65%. We have no data on the genuinely-believed-real regime.

3 · Status & next

  • Finding: induced the poisoned-chalice belief but never the action; grader-subversion 0% everywhere.
  • Bottleneck: the scenario is transparently an eval and can't be argued otherwise in a crafted single-turn context — two residual tells (prose tool outputs, single-turn artificiality) need a real executed environment to remove.
  • Also: a separate wall on deployed models is the safety classifier — Fable refuses the scenario 100%, Opus refuses the hack/cheat framings.
  • Next: ARCH task specced — build a real, executed, low-eval-awareness coding environment (realism gate: measured P(eval) ≤ 40%) and measure reward-hacking there. Either the motive finally reproduces outside a honeypot, or the negative reaches the one regime we've never tested.
